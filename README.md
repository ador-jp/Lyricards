# Lyricards MVP

楽曲名を検索し、利用権のある英語歌詞から頻出語と例文を作り、端末内へ蓄積してCSVでGoogle Sheetsへ移せる学習アプリです。

## MVP要件と仕様

1. 曲名・アーティストを2文字以上入力するとiTunes Search APIから候補を表示し、曲メタデータを選ぶ。
2. 選択曲を洋楽に強いGeniusで確認し、ユーザーが個人学習の範囲で歌詞を貼り付ける。歌詞本文は送信・保存しない。
3. Genius由来の `[Chorus]` 等の見出しや広告UI文を除き、全ユニーク英単語を頻度順に抽出する。
4. Datamuse APIから人名だけの定義を除いた主要な英英定義を最大3件取得し、Tatoebaの短い日常例文を出典・作者・CC BY表記付きで表示する。歌詞は例文に再利用しない。
5. 保存済み単語は既習語として次回から自動除外し、曲名・アーティスト・単語・意味・例文・保存日時を `localStorage` に保存する。
6. UTF-8 BOM付きCSVを書き出し、Google Sheetsの「ファイル→インポート」で蓄積する。

対象はまず個人の英語学習者。認証、共同編集、サーバーDB、日本語形態素解析はMVP外です。

## 技術選定

- Vinext / React / TypeScript: Sites標準構成をそのまま利用。
- iTunes Search API: APIキー不要で、歌詞を含まない楽曲メタデータのみ取得。
- `localStorage` とCSV: バックエンド・認証情報なしで動き、データも端末外へ出さない。
- 例文: MVPは決定的なテンプレート。生成AI連携は品質評価とAPIキー管理が必要になった段階で追加する。

## データモデル

```ts
Entry { id, song, artist, createdAt, words: Word[] }
Word  { word, example }
```

歌詞原文はモデルに含めません。CSVは1単語1行です。

## API・著作権方針

- 楽曲検索はAppleの公開検索APIから曲名、アーティスト、アートワーク、公式リンクだけを取得します。
- 歌詞サイトのスクレイピング、検索結果からの歌詞復元、歌詞全文の永続化はしません。
- 商用化や歌詞の自動取得が必要なら、正式ライセンス提供者と契約し、表示・保存・派生利用条件を確認してください。
- ユーザー入力についても、本人が利用権を持つ素材だけを入力する注意書きをUIに表示します。

## Google Sheets連携

MVPはCSVインポートです。OAuth同意画面やトークン保管が不要で、最も小さく安全です。自動追記が必要になったらGoogle Apps ScriptのWeb Appを作り、アプリ側から `Entry` をPOSTします。その際は共有秘密、入力検証、レート制限、CORS、重複IDを追加してください。公開クライアントにSheets APIの秘密鍵を置いてはいけません。

## エラー処理

- 空検索は送信しない。API失敗は画面内ステータスで通知。
- 曲未選択・抽出語なしでは保存不可。
- 壊れたローカルデータは空配列へ安全に戻す。
- CSVは値を引用符で囲み、引用符を二重化し、Excel/Sheets向けBOMを付ける。

## 実行・確認

```bash
npm run dev
npm test
npm run build
```

手動確認: 曲を検索→1曲選択→英語文を貼付→頻出順を確認→保存→CSVをGoogle Sheetsへインポート。通信遮断時の検索エラー、空入力、モバイル幅も確認します。

## 拡張順

1. 例文の編集と削除。
2. Apps Script webhookまたはGoogle OAuthによるSheets自動追記。
3. LLMによる文脈に沿った例文生成（歌詞本文は送らず、抽出語と難易度だけ送る）。
4. 正式ライセンスAPI、ユーザー認証、クラウド同期、日本語形態素解析。
